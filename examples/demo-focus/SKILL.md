# Demo Focus Skill

Use this example to confirm Orchill can find and selectively install a skill.

## Instructions

1. Read the user's task before acting.
2. State the goal and constraints briefly.
3. Make the smallest useful change.
4. Verify the result before claiming success.

This is an example skill bundled with Orchill. It is not intended to be an expert workflow.
