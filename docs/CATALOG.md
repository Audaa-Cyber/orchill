- [Browse all skills by category](../catalog/CATALOG.md)

The canonical metadata is `registry/skills.json`. Every local skill payload is organized as `skills/<category-slug>/<skill-id>/`, preserving nested references, scripts, assets, and other files. Git-backed entries remain remote.

**Review status:** 221 registry entries across 20 categories; 209 local payloads and 12 Git-backed entries. Imported instructions remain untrusted. Missing or unverified license/provenance data is not permission to redistribute. Review third-party license terms and security findings before publishing a package containing these payloads.
